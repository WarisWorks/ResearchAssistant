# ResearchAssistant

Getting Started

Clone the repository:

 git clone https://github.com/WarisWorks/ResearchAssistant
cd ResearchAssistant

Install dependencies:

npm install
# or
yarn install
# or
pnpm install

Run the development server:

npm run dev
# or
yarn dev
# or
pnpm dev
Open http://localhost:3000 in your browser to see the result.
